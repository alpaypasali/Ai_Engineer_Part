# NewsRoute — English News Classification

NewsRoute is an AI engineering learning project that assigns English news articles to one of four editorial topics: **World**, **Sports**, **Business**, or **Sci/Tech**. The CLI demo uses the selected **TF-IDF + Logistic Regression** model. A small, from-scratch Transformer was also trained for comparison.

## Dataset

- **Source:** [AG News on Hugging Face (`fancyzhx/ag_news`)](https://huggingface.co/datasets/fancyzhx/ag_news)
- **Training split used in this project:** 3,200 articles.
- **Validation split:** 800 articles, evenly balanced across four classes.
- **Held-out final test:** 7,600 articles from the original AG News test split.
- **Labels:** `0 = World`, `1 = Sports`, `2 = Business`, `3 = Sci/Tech`.

The 3,200 training and 800 validation articles came from an initial stratified sample of 4,000 articles from the original training portion. The original test split was reserved until the final evaluation.

## Models

**Selected inference model — TF-IDF + Logistic Regression**

- `TfidfVectorizer(max_features=5000, ngram_range=(1, 2), lowercase=True)`
- `LogisticRegression(max_iter=1000)`
- Model file: `models/tfidf_pipeline.joblib`
- Preprocessing artifact: `models/rare_words.json`

**Comparison model — Mini Transformer**

- Token embedding (`d_model=64`), sinusoidal positional encoding, one Transformer Encoder layer (4 heads, feed-forward dimension 128), padding mask, masked mean pooling, linear classification head.
- Trained from scratch for three epochs without pretrained language weights.
- Model weights: `models/newsroute_transformer.pt`
- Token vocabulary: `models/vocab.json`

## Results

| Model | Validation Accuracy | Validation Macro-F1 | Final Test Accuracy | Final Test Macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| **TF-IDF + Logistic Regression** | **0.8712** | **0.8711** | **0.8705** | **0.8701** |
| Mini Transformer | 0.7138 | 0.7108 | 0.7361 | 0.7360 |

The TF-IDF model was chosen using **validation metrics only**. Final test metrics were computed afterward without retraining, retuning, or changing the selection. Full precision/recall results are in `reports/final_test_metrics.csv`.

## Setup

Run these commands from the `NewsRoute` project directory:

```bash
python -m pip install -r requirements.txt
python -m nltk.downloader wordnet omw-1.4 stopwords
```

**Dependency note:** The CLI's preprocessing requires the `nltk` Python package. Ensure `requirements.txt` includes the locally tested version of `nltk` in addition to NumPy, pandas, scikit-learn, PyTorch, datasets, joblib, pytest, and matplotlib. The NLTK downloader command installs the required language resources; it does not install the `nltk` package itself.

The following existing files are required for the chosen CLI model:

```text
models/tfidf_pipeline.joblib
models/rare_words.json
```

Model files should only be loaded from trusted sources because `joblib.load()` can execute code when deserializing untrusted artifacts.

## Predict from the terminal

```bash
python predict.py "Football team wins championship"
```

Output format (the actual class is determined by the saved model):

```text
Input: Football team wins championship
Predicted Class: <World | Sports | Business | Sci/Tech>
```

The callable function `predict_news(text)` returns the predicted class name and rejects empty text, whitespace-only strings, `None`, and non-string inputs. Predictions are produced from saved weights; no training runs during inference.

## Tests

```bash
python -m pytest -q
```

Six input and artifact-handling checks passed in the user's current environment:

1. Empty string raises a meaningful error.
2. Whitespace-only string raises a meaningful error.
3. Missing model artifact causes an error rather than an invented prediction.
4. `None` is rejected.
5. Integer input is rejected.
6. Valid news text returns a supported class label.

## Limitations

- English-only, four-category classifier; other languages and taxonomies are unsupported.
- Historical AG News data may not reflect modern news or unseen publishers.
- Overlapping topics can cause wrong editorial routing; human review is advisable for uncertain or consequential cases.
- The 3,200-example training set is small, especially for training a Transformer from scratch.
- The original one-occurrence word filter was derived from the 4,000 sampled articles before the train/validation split, which is a limitation of the validation methodology.
- No independent deployment monitoring, latency benchmark, or contemporary-news evaluation has been completed.

See [model_card.md](model_card.md) for intended use, evaluation details, and risks.
